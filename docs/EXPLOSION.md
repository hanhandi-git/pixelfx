# 爆裂魔法 · Explosion

《为美好的世界献上祝福！》惠惠的爆裂魔法，四件一组：

| 节拍 | 文件 | 作用 |
|---|---|---|
| 咏唱 | `konosuba/explosion-chant` | 脚下血色魔法阵、八枚立起的符文、向上缠绕的暗红丝线 |
| 爆发 | `konosuba/explosion-strike` | 咒文收束成针、白闪、带芒的血红星、翻滚的火冠、碎石与焦土 |
| 余烬 | `konosuba/explosion-crater` | 烧穿的地坑、焦黑裂石、还在发光的裂缝、三柱细烟 |
| 整套 | `konosuba/explosion-ritual` | 念完 → 把法杖往下砸 → 被自己的一击掀退 → 跪坐在灰里 |

四件共用 `src/fx/konosuba/_lib.js`：两条渐变（`BLOOD` 咒文用的暗红、`CRIMSON` 爆发的血金）、
`floorSeal`（会自己写出来的地面法阵）、`blastStar` / `blastRays`（带芒的星）、`gatherMotes`
（向心收束的光点）、八枚原创 3×5 角形符文 `RUNES`。所以咏唱的法阵和爆发的法阵是同一套纹样，
只是后者的火更亮、边缘被冲开。

色板走“血 → 火 → 白”：`#10050c #2e0813 #5c0d1e #96142a #cf2230 #ff4a2a #ff8f3a #ffd36a`。
暗部留给咒文，亮部只给爆点、芒尖和核心，白只出现在闪帧与最热的核里。

## 节拍

**咏唱**（循环 4s）：法阵分三层“写”出来——外环先被描出，随后是刻度带与六芒星，最后八枚符文从
近侧一枚枚立起。环内是血红的实心光（`tone` 抖动），环外是一圈更暗的散光。围绕她的是一圈悬浮符文
（前后各半，反向转）和 34 条向上缠绕的 1px 丝线，颜色按“年龄”从橙红褪到暗红。空气从 84px 外
被收向胸口，三圈压力环在每个循环里各推出去一次。整个循环转满 360°，因为符文是八重、星是六重，
只有转满一圈接缝才对齐——所以这是无缝循环，念多久都行。

**爆发**（9s）：

1. 0–0.92s 收束：法阵重新写在目标脚下（同一个 `floorSeal`，更小更亮），四周气流拉成线冲向
   头顶 74px 处的一点，地面被吸起细尘。
2. 0.92–1.0s 成针：那一点缩到 3px，边缘先转白——这是唯一的预警，也是“她念完了”的信号。
3. 1.0–1.05s 白闪：两帧全屏白（`wash` 铺满画布 + 一个纯白圆盘），第三帧开始退。
4. 1.0–1.45s 星：`blastStar` 12 芒，从 80px 撑到 270px，核心白、体内金橙、射线轴比谷底更热，
   外圈加 16 道 1px 白针（`blastRays`）。同时贴地冲击环推开、光穹落下。
5. 1.0–2.4s 火冠：`Plume` 的火团边生边长，受热上升，滚成蘑菇冠；`Column` 从地面往上续火。
   两次二次爆（1.16s、1.31s）在两侧炸开，各自带一圈小环。
6. 1.05s 起抛石：30 块碎石按抛物线飞出去，带热的下落时拖火、落地生小火与尘；地面浮起碎石与
   细砂，外围摊开一层尘浪。
7. 2.2–9s 冷却：火冠从白热经橙红褪到暗红，烟从顶上翻出、化成灰片落下；余烬被上升气流带到
   4.6s；最后 1.5s 连焦痕一起淡掉，9s 清空。

**焦土**（6.5s）：坑是椭圆的（106×27），坑底压得更黑，外缘用抖动过渡到地面，不会像贴上去的
椭圆。坑口一圈连续的石唇（近侧两行、更亮，远侧一行、更暗）先立住形状，再压上 54 块焦石——每块
有影子、亮顶和暗底，热的时候顶上还有一点火色。13 条裂缝从坑心往外爬，2px 宽、中心更白，随时间
从橙红冷到暗红。坑心是熔池，4s 内收成暗红。三柱烟从不同裂缝升起，节奏各不相同；灰从上往下落，
落地即消失；最后 1.5s 一阵贴地尘雾涌进来把整片焦土吞掉。

**整套**（11.8s）：0–2.8s 咏唱（法阵 + 符文 + 丝线，姿势按每拍下沉一次）→ 2.8s 咏唱切断、
爆发的收束段接手（法阵换小、气流拉成线）→ 3.8s 砸杖、白闪、命中（hit-stop 0.09s、震屏 0.9）
→ 3.92s 被掀退（头后仰、双臂张开、脚下打滑）→ 5.5s 双膝落地 → 6.4s 坐进灰里，之后只剩呼吸般的
轻微起伏到 11.8s。`act.hits` 的 `t` 与爆发的白闪同帧。

## 用法

```js
import * as chant from "pixelfx/fx/konosuba/explosion-chant";
import * as strike from "pixelfx/fx/konosuba/explosion-strike";
import * as crater from "pixelfx/fx/konosuba/explosion-crater";
```

- 只要一发：`createFx(strike, { x, y })`，9s 自己走完。
- 念多久都行：`createFx(chant, { x, y })` 是循环，随时 `stop()`。
- 先念后炸：`chain([{ fx: chant, until: 3 }, { fx: strike, t: 2 }])`——`t` 提前 1s 是因为
  `strike` 自己带着最后一秒的收束，正好接在咏唱尾巴上。
- 炸完留疤：`createFx(crater, { x, y })` 单独放，6.5s 后清空；想常驻就改用循环或直接停在
  2s 的帧上。
- 换色：四件都读 `options.palette`（`fit` 取值），传一条 8 级由暗到亮的渐变即可；`stone` 改焦石
  的颜色。咏唱默认 `BLOOD`，爆发与焦土默认 `CRIMSON`，想统一风格就给两处传同一条。
- 四件都是固定种子（`options.seed`），同参数逐帧可复现。
