# 符纸：让一张纸真的在飘

| 项目 | 值 |
|---|---|
| 效果 ID | `pickups/paper-talisman` |
| 类型 | 循环 pickup（64×80，2.4s） |
| 优化前 commit | `3c340ed` |
| 优化后 commit | `955dfa2` |
| 源文件 | [paper-talisman.js](../../src/fx/pickups/paper-talisman.js) |

## 优化前

![符纸优化前](paper-talisman/before.gif)

朱砂边框、笔迹和印章都已经成立，但纸本身像一块硬卡片：摆动只有 0.05 rad，纸面几乎没有压缩，底边是固定的撕裂形，绳子也不动。

## 问题

1. **主摆动太小。** 0.05 rad 在 1x 下只有不到 1px 的倾斜，读不出“飘”。
2. **底边完全固定。** 撕裂边虽然参差，但每一帧一样，缺少纸被风带起来的形变。
3. **没有折痕光。** 纸的弯曲没有受光/背光变化，仍然是一个平面。
4. **绳结是死的。** 顶部的环只跟着纸整体旋转，没有自己的滞后。

## 优化思路

### 1. 纸的摆动来自“摆动 + 压缩”两层

单纯旋转会像一块板；给纸张一点横向压缩，才会像薄片在风里翻动：

```js
const pose = (ph) => ({
  y: -HOVER - 2.0 * Math.sin(ph * TAU),
  a: 0.11 * Math.sin(ph * TAU + 0.2),
  sx: 1 - 0.08 * (0.5 + 0.5 * Math.sin(ph * TAU * 2)),
});
```

`sx` 用两倍频率，和主摆动错开，避免整个动作只有一条正弦。

### 2. 底边做成行波，而不是固定锯齿

底边仍然保留原来的撕裂哈希，但叠一条从中间向两边增强的行波：

```js
const edge = smooth(0, 8, Math.abs(u));
const bot = 14
  + (Math.floor(u * 0.75 + 30) % 2 ? 0.9 : -0.6)
  - (Math.abs(u) > 7.4 ? 1.2 : 0)
  + 1.0 * Math.sin(ph * TAU * 2 + u * 0.55) * (0.3 + 0.7 * edge);
```

中间几乎不动，两个下角上下摆 1px 左右；在 1x 下，轮廓会一帧一帧地“卷”起来。频率是整数，seam 仍然闭合。

### 3. 折痕要跟着底边走，并且有光

在底边上方留一条 1px 的亮带，位置使用同一个 `bot`，所以它会随着纸边一起移动：

```js
if (v > bot - 1.4 && v < bot - 0.3) idx = Math.min(5, idx + 1);
```

这不是额外的贴图，而是“纸弯起来后朝光的一面”，比单纯加高光更像纸。

### 4. 绳子要迟一拍

绳环横向摆 0.9px，并从纸顶拉一条短绳连到环；绳画在纸层之前，所以只露出纸外的一小段：

```js
const cord = 0.9 * Math.sin(ph * TAU + 0.9);
const [tx, ty] = at(cord, -16), [tx0, ty0] = at(0, -14.5);
p.line(tx0, ty0, tx, ty - 1.8, R[2], 0.8);
p.ring(tx, ty - 3, 3.2, 1, R[3], 0.9);
```

## 优化后

![符纸优化后](paper-talisman/after.gif)

变化点：

- 纸张左右摆得更明显，并带 8% 的横向压缩。
- 底边两角有行波，轮廓不再固定。
- 底边上方有一条随纸边移动的折痕光。
- 绳环和纸的摆动错开，连接处更自然。
- 上下浮动从 1.6 提到 2.0，影子同步。

## 可复用清单

- [ ] **薄片类效果有“压缩/拉伸”吗？** 只旋转会像硬板，横向压缩才像纸。
- [ ] **边缘是固定的吗？** 给底边/布边加整数频率的行波，中间弱、边缘强。
- [ ] **折痕有光吗？** 弯曲处给一条跟随边缘的亮带，比额外高光更像材质。
- [ ] **绳/环有滞后吗？** 连接件晚半拍，整体才不是刚体。
- [ ] **波形的频率是整数吗？** 否则循环 seam 会跳。
