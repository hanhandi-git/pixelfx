# 效果优化手记

这里记录**已经提交过的效果优化**：优化前是什么样、问题出在哪、改了什么、怎么验证。目标不是写“效果说明”，而是把可复用的判断和手法留下来，下一次遇到“感觉不对但说不清”的效果时能快速对照。

## 目录约定

每个案例一个 Markdown，素材放在同名子目录：

```text
docs/refinements/
  README.md
  spirit-butterfly.md
  spirit-butterfly/
    before.gif
    after.gif
```

案例正文固定按这个顺序写：

1. **优化前**：GIF + 一句现状。
2. **问题**：具体是形态、节奏、朝向还是层次的问题。
3. **优化思路**：为什么这样改，附最小代码片段。
4. **优化后**：GIF + 变化点。
5. **验证**：命令和结果。
6. **可复用清单**：下次可以直接照做的检查项。

## 共通的优化顺序

1. **先看 1x 循环，不要只看 4x 静帧。** 1x 决定游戏里是否读得出来；4x 用来查像素和轮廓。
2. **先修主动运动，再加粒子。** 朝向、路径、节奏不对时，加 trail 和 glow 只会让“贴图感”更明显。
3. **让循环内有快慢。** 不要只改 `duration`；用整数频率的相位函数做“冲刺—悬停”，循环仍然无缝。
4. **主循环的幅度要够。** 扑翼、摆动、开合在 1x 下至少要能看出两三个明确姿态，不能只在 1px 内抖。
5. **次级运动要滞后。** 触角、飘带、远侧翅膀比主动作晚 1–3 帧，画面才有“跟随”而不是整体刚体平移。
6. **最后加运动特效。** 速度线、尾迹、翼尖闪光只做强调；任何一帧都不能盖住主体轮廓。
7. **收尾必须过 seam 和 check。** 所有周期项用整数频率；`t=0` 与 `t=duration` 的像素必须一致。
