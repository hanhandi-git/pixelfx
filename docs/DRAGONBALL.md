# 龙珠 · Dragon Ball ki arts

一套八式的「气」特效：两式循环（聚气、金色气焰），六式一次性招式（龟派气功波、贯穿钻光、元气弹、
气弹连射、气圆斩、太阳拳）。全部由代码绘制，带施术者动作（`act`）、固定种子、双缓冲
（颜色 + 加算光），既可单独播放，也能导出成 Cocos 的 PNG / JSON。

- 气：钴蓝到冷白的渐层，白色核心，边缘只在轮廓上抖动（dither）
- 金色气焰与气弹：琥珀金到白热，配 `GOLD` 色板
- 元气弹：冷蓝绿（`SPIRIT`），强调「从场地上被抽起来的光」
- 贯穿钻光：偏紫的 `DRILL` 色板，和龟派气功的钴蓝区分开

八式共用 `src/fx/dragonball/_lib.js`：球体、光束、螺旋钻、加算光晕、向内汇聚的线、贴地冲击环、
裂地、气焰舌、电弧碎点。所以它们看起来是同一门技法的不同招式，而不是八张风格各异的图。

## 节拍

**聚气**：循环内气从四周收向掌心（`inwardStreaks`），球体随呼吸胀缩、三条旋臂反向转、外壳被挤成
一圈薄环，每过半秒挤出一道压力环；绕球光点与地面冷光是持续的，没有起止。循环首尾同相。

**龟派气功波**：蓄（0–1.06s，腰侧掌心气团从 r=6 涨到 r=13，向内的气线加速，脚下浮尘）→ 推出
（1.06s，两帧硬闪 + 枪口光）→ 光束（1.06–2.2s，半径 10.5 的厚柱，白核外依次是青、蓝、深蓝三级，
柱身上三道压力箍以不同速度滑出，头部是白热圆盘）→ 命中（1.3s，光核、白环、三层贴地环、裂地、
`hotStar`）→ 收束与余烟（2.2–4.2s 清空）。光束长度、施术者姿态和 `act.target` 共用同一组常量，
所以手、枪口、命中点始终对齐。

**贯穿钻光**：双指抵额、气旋收紧（0–1.18s，掌前小球 + 两道反向环 + 紫电碎点）→ 射出（1.18s）→
钻光推进（1.18–1.5s，锥形柱体，两条螺旋棱线一前一后，暗面是向里转的凹槽）→ 命中（1.5s，白核、
三圈转动的环、`hotStar`、裂地、碎石）→ 抵住目标继续钻（1.5–2.5s，尖端三叶钻头每帧转 34 弧度，
碎屑与烟不断）→ 收束（到 4.0s 清空）。

**元气弹**：抬手（0.15s）→ 细丝从地面升起、加速汇入头顶的球（0–2.45s；球半径 5→28，边缘有绕飞
光点）→ 抛下（2.45s，球体沿平方加速落到目标，身后拖一串残影）→ 命中（2.95s，白闪、光穹三圈、
三层贴地环、十一条裂地、尘柱与金烬）→ 余烬与尘（到 5.6s 清空）。地面「被抽光」的感觉靠两条：
汇入前的竖直光丝、命中后的尘柱，中间没有别的光。

**气弹连射**：抬手（0.06s）→ 七发以 0.11s 间隔发出（0.28–0.94s），每发是一条 24 帧的解析彗尾
（白核 + 金边 + 拖尾点），落点各自散开（x 60→264，y −12→−38）→ 每发落点留 1.35s 的焦痕与余烬
→ 收手（2.7s 清空）。弹道是解析的，不存粒子状态，所以七发永远在同一帧打到同一处。

**气圆斩**：掌上转轮（0–0.85s，锯轮从 r=4 长到 r=17，八枚钩齿、白色轮毂、三条每帧重算的丝线）→
掷出（0.92s）→ 贴平飞行（0.92–1.42s，转速 34 rad/s，身后留下速度残点）→ 命中（1.42s，十字白光、
`hotStar`、火花与碎石）→ 切线冷却（1.42–1.9s 由白转金再暗）→ 2.9s 清空。

**金色气焰**：循环。外圈是一层宽而暗的火焰片（`k=0.55`），中圈是主焰（24 条舌，`k=0.8`），内层是
身体本身的白色热柱；电弧按 `loopNoise` 的相位断续出现在肩上，碎石按 `cycle` 升起，地面光环保持
两拍一胀。所有相位都用 `t / duration` 归一，首尾相接。

**太阳拳**：收光（0–0.42s，脸前光点从 r=1.2 长到 r=5.4，八颗光点绕它转）→ 放出（0.42s，整帧白闪
约 3 帧 + 十六道光芒 + 白核 + 贴地冲击环 + `hotStar`）→ 光芒回缩、残环外扩（0.5–1.2s）→ 残光漂移
（到 2.3s 清空）。白闪用 `p.rect` 铺满画布再淡出，而不是画一个会溢出画布的大圆。

| 贯穿钻光 | `#150a2c #2c1358 #4a1f8c #6b2fbc #9050e0 #c08cf0 #e8ccff #ffffff` |
| 地面岩石（裂地、碎石） | `#0e0e12 #1c1c24 #2c2c38 #42424f #5c5c6b #7d7d8c #a4a4b2 #d0d0da` |

明度顺序固定：暗底 → 四到五级中间色 → 小面积白热核心。所有特效都读 `o.palette`，任意长度色板会经
`fit()` 重采样，可以整门换色（比如把气换成紫、把金色气焰换成赤红）。`o.reach` 用来改招式落点。

## 播放与导出

```bash
# 逐帧看动作
node tools/act.mjs dragonball/ki-wave

# 渲染接触表与动图
node tools/render.mjs dragonball/ki-wave --gif
node tools/render.mjs dragonball/spirit-bomb --mp4
node tools/render.mjs dragonball --gif

# 导出到 Cocos 工程
npm run cocos:export -- dragonball/ki-wave
npm run cocos:export -- dragonball
```

浏览器 Gallery：

- 新素材筛选：`gallery/index.html?source=new`
- 分类：`gallery/index.html#dragonball`

## 改造要点

- 想换颜色：只改 `meta.options.palette`，或直接给 `KI` / `GOLD` / `SPIRIT` / `DRILL` 传新数组；
  `_lib.js` 里的 `fit()` 会把任意长度重采样成八级。
- 想换落点：改 `options.reach`（`ki-wave`、`drill-beam`、`spirit-bomb`、`ki-volley`、`destructo-disc`
  都读它）。画布尺寸要跟着改，`meta.size` 与 `origin` 决定地面在画面里的高度。
- 想换节奏：每个文件顶部都有 `D`、`FIRE`/`SHOT`、`HIT` 这组常量，`act` 的关键帧与 `draw` 的
  时间判断都引用它们，改一处即可整体前移或后移。
- 想接角色：`act.poses` 的手部（`fx/fy`、`bx/by`）是世界坐标偏移，改姿势时先跑
  `node tools/act.mjs <id>` 看手够不够得着（`check.mjs` 会报「手短了几像素」）。
- 想复用：整套的通用件都在 `src/fx/dragonball/_lib.js`，`kiOrb` / `kiBeam` / `corkscrew`（在
  `drill-beam.js` 内）/ `auraTongues` / `kiImpact` 都可以单独拿去拼新招。
