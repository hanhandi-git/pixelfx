# 忍法与仙法 · Ninjutsu & Senjutsu

一套十八式的查克拉忍术 / 仙术像素特效：十二式忍法、六式仙法。全部是代码绘制、带施术者动作
（`act`）、固定种子、双缓冲（颜色 + 加算光），可直接播放，也可导出成 Cocos 的 PNG / JSON。

- 忍法：青蓝查克拉，冷白高光；`ninjutsu/`
- 仙法：琥珀金查克拉 + 翡翠绿自然能量；`senjutsu/`

两套共用 `src/fx/ninjutsu/_lib.js` 里的球体、封印环、向内汇聚的查克拉线与浮游光点，所以十八式看起来
是同一门术法的不同招式，而不是十八张风格各异的图。

## 节拍

**螺旋丸**：循环内持续有查克拉从四周收束到掌心，球体随呼吸胀缩，外壳环与压力环一圈圈挤出；
三条旋臂在球面上反向转动，白核一闪一闪。循环无接缝。

**千鸟**：掌心聚雷（0–0.78s，雷球、短电弧、向手心收束的蓝白点）→ 短促突刺（0.78–0.82s，
一条白热短枪从掌心穿到目标，两道身体拖影）→ 命中（0.82s，白核、七道分叉、地环、碎石、烟尘和
冷却焦痕）→ 残弧与烟散尽（2.8s 清空）。这次改的是“掌中雷 + 突刺”的经典千鸟，不再是举着的长枪。

**千鸟突进**：结印蓄雷（0–0.52s，掌前雷球、脚边电弧、地面封印）→ 蹬地（0.58s，白环与尘）
→ 贴地突进（0.58–1.04s，本体按直线冲到 246px，`ghost` 姿态残影、掌后两条电流带、速度线和
脚下砂石一路拖出）→ 命中（1.04s，白核、九道分叉、地环、碎石、烟）→ 滑步、残弧与焦痕冷却
（2.7s 清空）。突进是直线常量速度，`act` 的 x 与特效共用同一条 `bodyX`，所以残影、手掌和落点
始终对齐。

**豪火球**：吸气（0–0.6s，余烬被吸进嘴边，口部发光）→ 吐球（0.66s，白闪与火舌）→ 火球飞行并
膨胀到半径 25（0.66–1.32s）→ 命中（1.32s，白闪、冲击环、火团、碎石、焦痕）→ 余火与烟（到 4.3s 清空）。

**水龙弹**：结印与脚下水涡（0–0.5s）→ 水柱升起，龙身由曲线脊梁展开（0.5–0.8s）→ 昂首、扑向目标
（0.8–1.56s）→ 命中水花、环形水冠、水墙、雨、积水（1.56s 起）→ 水汽散尽（3.9s 清空）。龙身是沿
三次贝塞尔曲线按弧长采样的圆管，背脊有浪花冠与一排背棘，尾端有尾鳍；头部有角、须、鬃、四鳍、开口的
颚、牙与眼；水涡里另有一道水柱和泡沫冠，命中后地面还会荡开三圈涟漪。

**影分身**：爆烟（0.12s）→ 两个分身从烟雾里滑出（0.16–0.55s，带两帧拖影）→ 站定，边缘爬过电弧
（0.8–1.5s）→ 散成烟（2.15–2.6s）。分身直接用本体同一套角色像素与颜色绘制，只降到 62% 不透明度，
所以脸、衣服、发色都和本体一致，只是偏透明；拖影也是同一副身体。

**超大玉螺旋丸**：自然能量汇聚（0–1.05s）→ 头顶巨球成形（0.45–1.18s）→ 砸下（1.55–1.9s）→
白闪、光穹、三层金环 + 一层绿环、裂地与绿焰（1.9s 起）→ 尘埃落定（4.4s 清空）。

**螺旋手里剑**：风中成形（0–0.66s）→ 掷出，拖影表示高速旋转（0.66–0.96s）→ 展开成研磨球，
地面被刮白、碎屑被吸起（0.96–2.2s）→ 向左右爆出两道风刃与冲击环（2.2s）→ 风散（3.5s 清空）。

**白激之术**：双手收力、金色仙纹环绕（0–0.58s）→ 白核 + 十六道光芒（0.58s，两帧硬闪）→
半球光穹与贴地冲击环（0.6–1.5s）→ 裂地由白转金、灰尘与金烬落下（到 3.0s 清空）。

**麒麟**：乌云聚拢、风向变冷（0–0.88s，云层内小雷、地面暗影、目标脚下冷色封印）→ 先导雷探路
（0.88–1.0s）→ 主雷贯穿（1.0s，白蓝雷柱、七道分叉、白核、地环、碎石、雨）→ 雨、烟与地面电弧
（到 3.2s 清空）。雷柱用显式分叉，不再让随机 fork 把画面撑宽。

**凤仙火**：吸气（0–0.56s，口边火星）→ 吐火，六颗火球以扇形弧线飞出（0.56–0.90s，各自拖两道暗尾）
→ 依次落地/命中（0.72–0.90s，白核、火星、地面小焦痕）→ 中间一颗命中目标（0.86s）→ 余烬与烟
（到 2.6s 清空）。火球是解析路径，不存粒子状态。

**天照**：写轮眼锁定（0–0.56s，施术者眼中红点、目标处红针）→ 点燃（0.56s，白心、红环、黑炎炸开）
→ 黑色火炎（0.6–2.8s，以黑烟团为体，七条黑舌、赤缝、橙边）→ 烬与余火（到 3.4s 清空）。黑炎的主体是
`C[0]`，靠赤色缝、橙色尖端和红色加算光把轮廓托出来。

**水阵壁**：结印（0–0.4s）→ 双掌按下，水墙升起（0.4–0.72s，逐像素半透明水幕、白色流线、碎泡沫冠、水珠）→ 维持
（0.72–1.7s，水纹、薄雾、地面水洼）→ 塌落（1.7–2.4s，水珠与涟漪）→ 水洼散尽（2.6s 清空）。
这是一个没有目标、只有施术者与墙的防御术。

**大突破**：吸气（0–0.5s，空气与尘土收向嘴边）→ 吹出风锥（0.5–1.4s，26 条速度线、三道压力锋、
树叶、砂石、贴地尘）→ 目标被白色冲击环钉住（0.82s）→ 尘落（2.4s 清空）。风本身不可见，靠白线、
压力锋和尘叶来画。

**土流壁**：结印（0–0.46s）→ 双掌拍地，石板墙从地里顶起（0.46–0.74s，按行延迟、尘土、碎石）
→ 维持（0.74–1.8s，石板纹理、裂缝、顶部亮边）→ 崩落（1.8–2.7s，石板下落、尘土）→ 2.8s 清空。
同样没有目标，墙是主体。

**五右卫门**：结印吸气（0–0.66s，口前油珠与仙纹）→ 油、风、火三股从口前绞出（0.66–1.1s，油流有暗琥珀的厚体、白色高光、翡翠风带）→ 火沿油流点燃（0.82s 起，火舌只挂在油边）→ 命中（1.42s，燃烧油浪、油池、烟与飞溅）→ 余火与烟（到 3.8s 清空）。油、风、火是同一股的三层材质，不是三团并排的火。

**明神门**：结印、仙光柱开缝（0–0.8s）→ 两道侧门落下（1.06/1.30s，尘、金环、裂地）→ 主门砸在目标上（1.54s，更大的尘环、木屑、翡翠光点）→ 鸟居留在场上，金光退去（到 3.4s 清空）。门是朱红木、黑铁帽、金边和一点仙纹，不是三块红色矩形。

**千木龙**：结印（0–0.64s）→ 三条根须破土，木龙像水流一样从地里长出来（0.7–1.4s，身体先长、头后现）→ 三条龙互相缠行、抬头蓄势（1.4–1.9s）→ 三口依次咬中目标（2.12/2.27/2.4s，每一口都带树皮、苔藓和琥珀树汁）→ 根系从地面收拢成笼（2.4s 后），木尘、碎皮与落叶散开（到 4.2s 清空）。木龙的身体是树皮、苔藓和会流动的琥珀树汁，不是水柱换色。

## 改造要点

- 想让招式打得更远（豪火球 / 超大玉 / 螺旋手里剑）：改 `meta.options.reach`、文件里的 `TARGET` 常量，并同步 `act.target.x` 与 `act.dust` 的落点（`act.hits` 只管定格与震屏）。
- 想换施术者动作：每个文件顶部的 `act.poses` 是唯一的身体数据，手的位置（`fx/fy/bx/by`）与特效
  发射点（如 `HX/HY`、`GY`）要保持一致。
- 想让球更大：`chakraOrb` 的半径是参数，但外壳环、核心比例、旋臂密度都按 1x 像素设计，超过约 40px
  需要补一层细节（更多旋臂、第二层壳）。
- 影分身的分身数量与站位：`CLONES` 数组，`x` 是左右偏移；再多会碰到画布边缘。
- 命中定格、震屏、受击颜色都在 `act.hits`：`stop` 是冻结秒数，`shake`/`amp` 是震屏，`skin` 是受击染色。
